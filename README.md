# 온기 카페 랜딩 페이지

가상의 카페 "온기 카페"를 소개하는 간단한 한 페이지짜리 랜딩 페이지예요. AI 에이전트 수업 실습용으로 Claude Code와 함께 만들었어요.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 스타일시트 (반응형 레이아웃, 카페 톤의 색상) |

## 실행 방법

빌드 과정 없이 `index.html`을 브라우저로 열면 바로 확인할 수 있어요.

## 참고

- 카페 이름, 메뉴, 가격, 주소, 전화번호는 모두 예시 내용이에요.
- 외부 라이브러리나 이미지 없이 HTML과 CSS만 사용해요.
